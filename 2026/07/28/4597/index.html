    • 開発メモ その491 Windows をリセット後、BitLocker で CRC エラー

    Introduction

    掲題の通り。
    元は会社でマシンの再セットアップ時に発生した事象。
    自宅でやっても再現したので、再現性 100% に思える。

    How to reproduce?

    再現手順は簡単。

    1. BitLocker で OS ドライブ以外を暗号化

    テストデータを配置。

    1. Windows の回復機能を使って初期化

    「すべて削除する」を選択。

    「ローカル再インストール」を選択。

    「次へ」を選択。

    「次へ」を選択。

    「リセット」を選択。

    しばらくすると再起動がかかるのでセットアップを実施。

    1. 再インストール後、BitLocker で暗号化されている OS 以外のドライブに警告アイコンが出現

    BitLocker が中断されているので「保護の再開」を選択。

    「ウィザードの初期化に失敗しました データエラー（巡回冗長検査 (CRC) エラー）です。」、と。
    自動ロック解除の有効化 という表示があり、自動ロックが無効化されているような表示にも見えるが、暗号化されたドライブは普通に表示できる。

    How to resolve?

    BitLocker Drive Encryption - Data error (cyclic redundancy check) という Micorosoft Q&A で回答が。

    OK, found the answer:
    http://social.technet.microsoft.com/Forums/windows/en-US/db7030e5-4c37-46dc-b0ea-492f3e1ef76f/data-error-cyclic-redundancy-check?forum=w7itprosecurity
    Running the following as an admin will do the trick:
    manage-bde -autounlock -clearallkeys C:
    Note that it has to be C: even if the “auto-unlock” drive you’re trying to set up is not C:. Then reboot the system, and unlock the BitLocked drive. Now “auto-unlock” option should work.

    自動ロック解除の有効化 が表示されているドライブ、つまり CRC エラー が発生しているのが C ドライブ以外であっても C ドライブに対して manage-bde -autounlock -clearallkeys を実行する必要がある、とのこと。

    ということで管理者権限を付与したコマンドプロンプトを起動し、下記を実行。

    そして再起動。

    再起動後、 保護の再開 を実行すると、中断状態が解除され、 自動ロック解除の有効化 が 自動ロック解除の無効化 に戻り正常化する。

    ドライブアイコンの警告表示も消えていることが確認できる。
    当然データも問題なく表示できた。
